# 📊 Client Lead Management System (Mini CRM)

A full-stack **Client Lead Management System (Mini CRM)** designed for agencies, freelancers, and startups to manage incoming leads efficiently.

This system allows businesses to capture, track, and convert leads into clients through a structured admin dashboard.

## 🎯 Objective

The goal of this project is to simulate a real-world CRM system that helps businesses:

- Store incoming leads from contact forms
- Track lead status (New → Contacted → Converted)
- Add follow-up notes
- Manage clients securely through an admin panel

---

## ✨ Features

### 🔹 Lead Management
- View all incoming leads in a structured dashboard
- Update lead status (New, Contacted, Converted)
- View detailed lead information

### 🔹 Follow-up System
- Add notes for each lead
- Track communication history

### 🔹 Authentication
- Secure admin login system
- Protected routes for authorized users only

### 🔹 Dashboard
- Clean and modern UI
- Centralized lead overview
- Organized workflow for sales tracking
